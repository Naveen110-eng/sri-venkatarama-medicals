ONE-TIME FREE SETUP
1. Go to https://console.firebase.google.com/ and sign in with the admin Google account.
2. Create a Firebase project, e.g. sri-venkatarama-medicals.
3. Add a Web App in Project Overview and copy its Firebase config into firebase-config.js.
4. Authentication -> Sign-in method -> enable Google.
5. Authentication -> Settings -> Authorized domains: add your published website domain.
6. Create Firestore Database (production mode). In Rules, paste the Firestore rules from firebase-rules.txt and Publish.
7. Build -> Storage -> Get started. In Rules, paste the Storage rules from firebase-rules.txt and Publish.
8. Publish all files on a static host that supports HTTPS (e.g. GitHub Pages). Keep all four files together in the same folder.
9. Open your published domain + /admin.html and sign in with the authorised Google account.
10. Add products in the admin page. They will appear on the public homepage automatically.

SECURITY
- Do not share Firebase project owner access, passwords, or OTPs.
- Admin page hides itself from other Google accounts, and database/storage rules also restrict writes to the specified email.
- Public visitors can read published product records and product images.
- Do not put private keys or service-account JSON in website files.
